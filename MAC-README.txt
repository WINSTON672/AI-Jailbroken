DeepSeek Desk for macOS — experimental 0.3.0

Download mac-arm64.dmg for Apple Silicon or mac-x64.dmg for Intel.
Open the disk image and drag DeepSeek Desk to Applications.
This build is unsigned and not notarized. macOS may require explicit approval in System Settings > Privacy & Security after you attempt to open it.

Chat, web research and workspace tools use a local OpenAI-compatible model server configured in Settings. Model weights are not included. The exact 1017 CUDA runtime installer is Windows/WSL/NVIDIA only and does not run on macOS. No replacement model is downloaded automatically.
