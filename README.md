# DeepSeek Jailbroken App

Windows desktop app for the selected DeepSeek V4.1 Flash 1017 UNCENSORED FP8 checkpoint, with local chat, web search, file access and reviewed commands.

[Download the Windows installer](https://github.com/WINSTON672/deepseek-desk/releases/tag/deepseek-desk-v0.3.0).

The installed application is currently named **DeepSeek Desk**. Open **Set up exact DeepSeek 1017** to check hardware and set up the model. This app uses the specified third-party checkpoint; it does not modify or verify the checkpoint's refusal behavior itself.

Model weights are not bundled. This experimental reference runtime needs very large GPU, RAM and storage capacity, and full CUDA inference remains unverified. Hardware checks run before the model download. No smaller model is substituted.

See [README.txt](README.txt) for setup and development instructions. Upstream model code retains its [MIT license](runtime/LICENSE).
